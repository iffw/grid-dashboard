# 网格看板 · 一期 使用说明

一期范围：M1 振幅统计 + M2 区间与格距建议 + M3 阶梯推演（固定区间）。
回测（M4）和实盘监控（M5）是二期、三期，还没做。看板只读，不下单。

## 在 Mac 上打开（5 步）

1. 把整个 `grid_dashboard` 文件夹拷到 Mac 上（放桌面就行）。
2. 双击 `index.html`，用 Chrome 或 Safari 打开。
3. 顶部选好交易对（BTC / CRCL / SOXL）、K 线周期（默认 4H）、天数（默认 30）。
4. 点蓝按钮「拉取数据并计算」——页面会自己去 OKX 拉数据，不需要任何密钥。
5. 自上而下用：先看振幅数据 → 在区间建议里挑一个，点「用此区间填推演」→ 到阶梯推演点「生成推演表」，看最坏情形那几行。

全局参数（保证金、杠杆、手续费等）改完，点「按新参数重算」即可，不用重新拉数据。

## 如果拉不到数据（备用方案）

浏览器直连 OKX 失败时（页面会提示改用本地文件），用文件夹里的取数脚本：

1. 打开 Mac 的「终端」App。
2. 输入 `cd ` 后把 `grid_dashboard` 文件夹拖进终端窗口，回车。
3. 输入 `python3 fetch_data.py`，回车。看到三行"xxx 根 -> xxx.json"就是成功了（它会把三个标的 90 天 4H 数据存进 `data/` 文件夹）。
4. 回到浏览器页面，再点一次「拉取数据并计算」，页面会自动改用本地文件。
5. 想刷新数据，重跑一次第 3 步即可。

如果终端提示没有 python3：先在终端跑一次 `xcode-select --install` 装好苹果的命令行工具，再重试。

注：本地文件是生成那一刻的快照；浏览器直连成功时永远优先用最新数据。

## 文件清单

| 文件 | 作用 |
|---|---|
| `index.html` | 看板页面，双击打开就是它 |
| `grid-core.js` | 全部计算（振幅/区间/推演），公式都在里面，可审计 |
| `fetch_data.py` | 备用取数脚本（见上） |
| `data/` | 本地数据文件（脚本生成；没有也不影响直连模式） |

## 口径速查（与页面标注一致）

- 振幅 =（最高 − 最低）/ 最低；样本为已收盘 K 线。
- 建议格距 = max（日均波幅 × 格距系数，往返成本下限）；往返成本下限 = 2×（单边手续费 + 单边滑点）+ 每往返资金费分摊。
- 候选区间：A 实际高低点 ± 缓冲；B 振幅投影（现价 ×(1 ± 平均振幅×√根数），激进/稳健两档天数）；C 收盘价 P5–P95 分位带。
- 阶梯推演：做多开局按上方卖格数买底仓、下行逐格加仓；做空镜像；中性开局零仓、两边开仓。
- 强平价是逐仓简化估算（多头：（均价×数量 − 保证金）/（数量×(1 − 维持保证金率）），只用于开单前看最坏情形，**以 OKX 实际为准**。

开网格前先回答手册那句话：这个标的单边走到底，我死在哪一格？
推演表最下面/最上面那一行，就是答案。
